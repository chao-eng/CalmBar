  • ✨ 支持左右风扇联动调速与独立控制
  • ✨ 实时监测 CPU 核心温度、SoC 与电池传感器
  • ✨ 软件退出或休眠自动交还 SMC 官方托管，安全无风险

📖 软件安装与授权指南

步骤 1

下载与放入应用程序

从 GitHub Releases 或夸克网盘下载发布的 CalmBar.app（或 Zip 压缩包），将其拖入 /Applications（应用程序）文件夹中即可。

步骤 2

首次运行授权（绕过 Gatekeeper 隔离）

由于本项目为个人独立开源软件，未集成 Apple 商业付费证书，在 macOS 上直接双击打开时，系统安全机制（Gatekeeper）可能会拦截并提示 “应用程序已损坏，无法打开” 或 “无法验证开发者”。

在 macOS 终端（Terminal）中执行以下命令移除系统隔离属性即可正常运行：

移除 Gatekeeper 隔离标记 
sudo xattr -rd com.apple.quarantine /Applications/CalmBar.app
💡 提示：CalmBar 内部内置的 「应用去隔离」 工具亦支持直接拖拽任意 App 一键执行修复。
源码编译与构建 (针对开发者) 
git clone https://github.com/chao-eng/CalmBar.git
cd CalmBar && bash app/build_app.sh
系统要求：macOS 14.0 (Sonoma) 或更高版本 • 适用芯片：Apple M1 / M2 / M3 / M4 系列及 Intel Mac
