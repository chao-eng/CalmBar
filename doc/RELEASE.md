## 🚀 v2.0.1 (Latest) — 2026-08-20

### 🎨 控制中心交互重构 (Control Center UI/UX Modernization)
- **快捷工具 4 列磁贴栏**：将 OCR 截屏识字、剪贴板历史、开发清理中心与应用去隔离重构为水平磁贴，高度大幅压减。
- **系统守护 2 列紧凑网格**：防休眠、充电保护、自然滚动、Music 拦截与菜单收纳采用 2 列紧凑卡片排版。
- **视觉减负与高度优化**：整体垂直弹窗高度缩减约 50%，清除静态长文本副标题，转为原生 Tooltip 与动态状态徽标；统一原生控件风格。

## 🚀 v2.0.0 — 2026-08-19

### 🧩 模块平台化架构 (Feature & Service Architecture)
- **Feature Layer 抽象体系**：建立 `CalmFeature` 协议与 `FeatureManager` 统一生命周期注册表，支持按类别、状态与权限动态查询与调度。
- **Service Layer 门面抽离**：抽象 `HelperService`、`FanService`、`BatteryService` 与统一 `ServiceError`，解耦业务策略与底层 XPC / SMC 通信细节。
- **Dashboard 模型解耦**：引入 `DashboardViewModel` 与 `FeatureDashboardItem`，精简首页对底层 Manager 的直接耦合。

### ⚡ Command Palette 悬浮命令面板
- **Spotlight 风格命令搜索**：支持通过快捷键 `⌥ + ⌘ + K` 或面板图标随时唤起居中命令浮层，支持标题、拼音别名与分类极速检索。
- **统一命令执行管道**：内置 10+ 项高频核心命令，执行前统一进行权限前置校验并提供即时反馈。

### 🛡️ 权限与功能双向映射
- **透明度进一步升级**：权限安全看板直观展示辅助功能、特权助手、屏幕录制与完全磁盘访问所关联的具体功能，并提供缺失时的优雅降级。

### 🔄 RecoveryCoordinator 统一安全恢复
- **集中式生命周期恢复**：集中收敛应用退出、系统睡眠时的风扇自动控制恢复、充电策略重置与电源断言释放，确保底层状态幂等安全。

## 🚀 v1.5.0 — 2026-08-19

### 🔋 电池 SMC 控制硬件安全与熔断保护 (Battery Hardware Safety)
- **底层安全熔断机制 (Safety Melt)**：集成 `BatterySafetyPolicy`，当电量 $\le 15\%$ 或电池温度异常升高（$\ge 45^\circ\text{C}$）时，系统立即强行终止放电并取消阻断，确保硬件电芯绝对不过放。
- **特权 Helper 异常看门狗与退出回滚**：完善生命周期钩子，当 App 退出、进程异常终止或系统即将睡眠时，自动调用 `resetToDefaults()` 安全交还 SMC 控制权。
- **机型能力探测与写入状态校验**：细化针对具备 `CHTE`/`CH0C`/`CH0I`/`CHIE` 寄存器的 Mac 机型兼容性校验与状态反馈。

### 🛡️ 统一系统权限中心 (Permission Center)
- **透明可信的权限管理看板**：新增 `PermissionManager` 与 `PermissionCenterView` 界面，集中管理与展示 Accessibility、Privileged Helper、Screen Capture 与 Full Disk Access 四大核心权限。
- **清晰说明与一键跳转**：详细列明各项权限的用途与本地运行保障，支持一键激活特权助手及一键直达 macOS 系统设置。

### ⏱️ 全局系统事件协同与节能调度 (SystemEventCoordinator)
- **睡眠与锁屏自适应**：统一监听 `willSleep`、`didWake`、`screensDidSleep`、`sessionDidResignActive` 及锁屏/解锁通知。
- **动态暂停轮询**：屏幕息屏、锁屏或休眠时，自动暂停剪贴板监控 (0.5s) 与电池轮询等 Timer；唤醒或解锁后即时恢复，彻底消除息屏期间的后台无效唤醒。
- **按需生命周期**：当用户在设置中关闭某项功能时，彻底销毁其对应的后台 Timer。

### 📝 文案客观与严谨化优化
- **防离开机制说明修正**：客观阐明基于 `IOHIDSystem` 闲置计数的轻量微动模拟原理及针对特定服务端心跳软件的技术边界。
- **文档与术语规范**：全面剔除过度绝对化的宣传词汇，提升项目的工程专业度与可信赖度。

## 🚀 v1.4.0 — 2026-08-19

### 🗑️ 软件卸载与深层残留清理 (App Cleaner)
- **多线程索引扫描**：并发扫描系统与用户目录下的全部应用，自动提取应用架构（Apple Silicon / Intel / Universal）、图标、Bundle ID、安装体积及运行状态。
- **深层残留嗅探引擎**：深度扫描 `~/Library` 与 `/Library` 下 20+ 个关键目录（`Application Support`, `Caches`, `Containers`, `Group Containers`, `Preferences`, `Saved Application State`, `HTTPStorages`, `Logs`, `LaunchAgents` 等），基于 Bundle ID 衍生前缀、名称变体及安全黑名单精准匹配应用残留文件。
- **完全免密静默移入废纸篓**：多层级安全回退机制（系统原生 `trashItem` ➔ 用户态 `.Trash` 移动 ➔ 用户态 `removeItem`），完全避免系统管理员密码弹窗打扰，误删可在废纸篓中随时一键放回原处。
- **外部应用拖拽即时分析**：支持直接从访达将任意 `.app` 拖入清理窗口，即时分析其在系统中的所有关联文件。

### 🛠️ 开发者专属深度清理 (Developer Cleaner)
- **24+ 款主流开发工具链缓存**：
  - **Apple / iOS**：Xcode (`DerivedData`, `Archives`, `CoreSimulator/Devices`, `DeviceSupport`, `DocumentationCache`), CocoaPods, SwiftPM, Carthage；
  - **Web / JS**：Npm, Pnpm, Yarn, Bun, Deno；
  - **Python / AI**：Pip, Poetry, Uv, Conda, Pyenv；
  - **IDE**：VS Code, Cursor, Zed, JetBrains, Android Studio；
  - **Rust / Go / Java / Flutter**：Cargo, Go Modules, Gradle, Maven, Pub；
  - 支持一键清空内部缓存、整目录移入废纸篓与在访达中即时定位。
- **IDE 孤立工作区清理 (Orphaned Workspace Storage)**：
  - 自动解析 VS Code / Cursor / VSCodium 的 `workspace.json`；
  - 精准识别工程源码已被删除但缓存依然残留的“孤儿工作区”，支持一键批量清理释放数 GB 磁盘空间。
- **Pip 全局包管理器 (Pip Packages)**：
  - 自动探测当前系统的 Python 3 解释器；
  - 完整读取全局第三方包列表与体积，支持多选批量一键卸载。

### 🎨 交互与系统整合
- **独立原生双栏清理窗口**：支持应用体积与架构排序、实时搜索、即时加载与流畅的过渡动画。
- **状态栏与通用设置**：在主面板快捷操作与通用设置中支持自由控制清理模块入口。

## 🚀 v1.3.0 — 2026-08-19

### 📋 剪贴板历史记录 (Clipboard History)
- **多格式捕获**：支持纯文本、富文本 (RTF/HTML)、截图位图、访达文件、链接及颜色 HEX 码的自动监听。
- **图片智能升格**：访达复制图片文件自动升格为图片类型并即时生成高清缩略图与尺寸信息。
- **Vision OCR 提取**：后台自动提取图片中英日韩多语言文字，并集成二维码/条形码自动解码。
- **二维码去噪**：空间感知隔离算法自动屏蔽二维码矩阵像素引起的伪字符噪点。
- **智能去重置顶**：重复复制相同内容时自动累加计数并实时刷新 OCR 识别结果。
- **隐私敏感过滤**：自动忽略 1Password、Bitwarden 等密码管理器及系统瞬态复制内容。
- **独立管理面板**：提供关键词搜索、格式分类筛选、Pin 固定保护与容量 LRU 自动淘汰机制。
- **多模态写回**：复制图片条目时同时写回位图与文件对象，支持在聊天软件粘贴图片及在访达粘贴文件。

### 🐛 缺陷修复
- **OCR 弹窗删除同步**：修复 OCR 悬浮预览弹窗点击「删除记录」因 UUID 实例不一致导致未生效的问题。

## 🚀 v1.2.0 — 2026-08-18

### 🔤 屏幕识字与条码解析 (Vision OCR)
- **原生 Vision 引擎**：基于 Apple Vision 深度学习模型实现选区文字与二维码/条码秒级高精提取。
- **中英混排防乱码**：支持简体中文、繁体中文、英语、日语等混排自动检测与语言纠错。
- **URL 智能提取**：自动识别提取文本中的网页链接并提供 Safari 一键直达。
- **历史归档管理**：JSON 原子持久化、支持搜索、分类筛选、单项删除、一键清空与上限控制。
- **毛玻璃悬浮卡片**：大尺寸舒适排版，支持一键复制、删除记录与可调倒计时自动消失。
- **截屏防遮挡**：触发截屏识字时菜单栏主面板即时平滑收起，确保视野无遮挡。

## 🚀 v1.1.0 — 2026-08-18

### 🔋 电池健康与充电上限 (Battery Charge Limit)
- **硬件级充电阻断**：通过 SMC 寄存器在电量达到设定上限（如 80%）时阻断充电并切换为适配器旁路供电。
- **回差巡航模式**：支持设置回差区间（如 75%~80%），防止临界点高频微充微放。
- **临时满电与放电**：支持一键充至 100%（单次生效）以及断开适配器输入的主动放电。
- **安全失效保护**：退出或异常断开时自动复位 SMC 寄存器交还系统默认托管。

### 🎵 媒体拦截与防休眠
- **noTunes 启动拦截**：秒级静默拦截蓝牙耳机或媒体键唤起的 Apple Music，并支持无缝拉起替代播放器。
- **Caffeine 防休眠**：IOKit 临时电源断言阻止系统休眠，支持多档定时预设与重启状态保持。
- **防离开模拟器**：空闲时自动发送像素级微动，防止办公软件（Teams/Slack/飞书/钉钉）被误判离开。

### 🛡️ 系统工具与界面升级
- **Gatekeeper 去隔离**：一键清除应用 `com.apple.quarantine` 属性并支持 Ad-hoc 深度重签名修复。
- **动态胶囊 Tab 栏**：偏好设置引入弹性展开胶囊导航栏与原生弹簧动画。
- **面板自由定制**：支持自由勾选隐藏任务栏各模块，布局紧凑自适应。
- **温度算法修正**：严格按 Apple IOKit 规范修正电池温度读取公式。

## 🌿 v1.0.0 (Initial Release) — 2026-08-10

### 💨 核心功能基石
- **AirPulse 硬件温控**：实时采集 Apple Silicon 与 Intel 芯片温度，提供自动、手动与智能温控加速曲线。
- **Hidden Bar 菜单栏收纳**：通过分隔符与快捷键实现低频图标折叠隐藏、开机静默收纳与自动收起。
- **Scroll Reverser 滚轮解耦**：解耦外接鼠标与触控板滚动方向，鼠标反转的同时触控板保持原生手势。
