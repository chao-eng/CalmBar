## 🚀 v2.3.1 (Latest) — 2026-09-04

### 🖥️ 无风扇机型适配 (Fanless Mac Adaptation)
- **能力自适应纯温度监控**：引入 `FanCapability`（`unknown` / `fanless` / `hasFans`）作为降级单一事实来源，依据 SMC `FNum` 寄存器一次性探测风扇数量；仅确认存在可控制风扇时才暴露温控调速全链路。
- **库层写保护**：`FanController` 所有写风扇入口（`setLinkedFraction` / `setIndependentFraction` / `setLinkedRPM` / `setAuto` / `restoreSystemControl` / `enableManualMode`）内部 `guard capability.supportsFanControl` 静默短路，杜绝无风扇机型产生任何 SMC 写操作。
- **状态层门控**：`ThermalMonitor` 在无风扇机型恒为只读监控，`applyCurrentMode` / `writeFanFraction` / `restoreSystemControl` 直接短路；安全策略仅保留 warning / critical 档用于过温提醒徽标，不再暗示正在主动散热。
- **UI 与引导裁剪**：控制中心、设置页与命令面板不再展示风扇模式 / 转速滑杆 / RPM 读数 / 联动开关；隐藏「一键激活特权助手」入口，权限中心文案明确「温度读取为只读 SMC 操作，无需风扇调速」，设置侧栏不再提示温控需特权助手。
- **文案统一**：权限用途说明与权限中心提示统一以「已确认无内置风扇」为判据，避免 SMC 暂断时误导宣称被动散热。

### ⌨️ 命令面板交互增强 (Command Palette Dismiss)
- **点击外部 / App 失活自动关闭**：点击面板外部区域（本 App 其它窗口或其它 App / 桌面）或 App 失活（⌘Tab、切到其它 App）时自动收起命令面板。
- **与状态栏面板互斥**：命令面板与控制中心 Popover、偏好设置窗口互相收起，避免多浮层并存；全局事件监听回调切回主执行体再执行 AppKit UI 操作。

### 🧪 回归测试
- 新增 `FanCapability` / `FanlessAdaptation` / `FanlessSimulation` / `CommandPaletteDismiss` 四组回归测试，覆盖能力语义、降级门控、命令/权限裁剪、面板失活关闭契约。

## 🚀 v2.3.0 — 2026-08-26

### 📋 剪贴板历史失焦自动隐藏 (Clipboard History Auto-Hide on Blur)
- **偏好设置独立交互配置**：在「偏好设置 - 剪贴板」的「历史窗口与快捷操作」中新增 **「允许窗口失焦隐藏」** 开关。
- **失焦智能隐藏与防误触**：开启后，通过快捷键 `⌥⌘V` 或设置页打开剪贴板历史窗口，当点击外部区域或切换应用使其失去焦点时自动隐藏窗口；且在窗口内弹出子表单或操作对话框时智能保持打开状态。
- **生命周期严谨管理**：基于 `NSWindowDelegate` 监听 `windowDidResignKey` 与 `windowWillClose`，确保内存及时释放与窗口状态一致。

### 🏎️ 硬件温控与多风扇自适应排版 (Multi-Fan Layout & Scaling)
- **单行文本自适应缩放**：风扇仪表盘卡片引入单行约束与 `minimumScaleFactor` 动态缩放，彻底消除高转速数值 (RPM) 在不同屏幕分辨率下的折行现象。
- **设备类型自适应标题与间距**：单风扇设备（MacBook Air / 部分 Pro）动态展示为「风扇」，双风扇设备动态区分「风扇 1 / 2」，结合优化的卡片 Padding 与网格间距，呈现原生精准质感。

### 🛡️ 权限中心生命周期感知与刷新 (Background Items & Auto Refresh)
- **macOS 13+ 后台项目权限指引**：增加对「允许在后台运行」(Background Items) 权限的自动探测与精准指引。
- **应用激活生命周期自动刷新**：监听 `NSApplication.didBecomeActive` 通知，当用户从「系统设置」授权返回后自动刷新权限状态，无需手动重复点击。
- **控制中心轮询与快捷重试**：控制中心权限横幅新增快速重试入口，与各设置页及权限看板保持全局实时一致。

## 🚀 v1.5.0 — 2026-08-19

### 🔋 电池 SMC 控制硬件安全与熔断保护 (Battery Hardware Safety)
- **底层安全熔断机制 (Safety Melt)**：集成 `BatterySafetyPolicy`，当电量 $\le 15\%$ 或电池温度异常升高（$\ge 45^\circ\text{C}$）时，系统立即强行终止放电并取消阻断，确保硬件电芯绝对不过放。
- **特权 Helper 异常看门狗与退出回滚**：完善生命周期钩子，当 App 退出、进程异常终止或系统即将睡眠时，自动调用 `resetToDefaults()` 安全交还 SMC 控制权。
- **机型能力探测与写入状态校验**：细化针对具备 `CHTE`/`CH0C`/`CH0I`/`CHIE` 寄存器的 Mac 机型兼容性校验与状态反馈。

### 🛡️ 统一系统权限中心 (Permission Center)
- **透明可信的权限管理看板**：新增 `PermissionManager` 与 `PermissionCenterView` 界面，集中管理与展示 Accessibility、Privileged Helper、Screen Capture 与 Full Disk Access 四大核心权限。
- **清晰说明与一键跳转**：详细列明各项权限的用途与本地运行保障，支持一键激活特权助手及一键直达 macOS 系统设置。

### ⏱️ 全局系统事件协同与节能调度 (SystemEventCoordinator)
- **睡眠与锁屏自适应**：统一监听 `willSleep`、`didWake`、`screensDidSleep`、`sessionDidResignActive` 及锁屏/解锁通知。
- **动态暂停轮询**：屏幕息屏、锁屏或休眠时，自动暂停剪贴板监控 (0.5s) 与电池轮询等 Timer；唤醒或解锁后即时恢复，彻底消除息屏期间的后台无效唤醒。
- **按需生命周期**：当用户在设置中关闭某项功能时，彻底销毁其对应的后台 Timer。

### 📝 文案客观与严谨化优化
- **防离开机制说明修正**：客观阐明基于 `IOHIDSystem` 闲置计数的轻量微动模拟原理及针对特定服务端心跳软件的技术边界。
- **文档与术语规范**：全面剔除过度绝对化的宣传词汇，提升项目的工程专业度与可信赖度。

## 🚀 v1.4.0 — 2026-08-19

### 🗑️ 软件卸载与深层残留清理 (App Cleaner)
- **多线程索引扫描**：并发扫描系统与用户目录下的全部应用，自动提取应用架构（Apple Silicon / Intel / Universal）、图标、Bundle ID、安装体积及运行状态。
- **深层残留嗅探引擎**：深度扫描 `~/Library` 与 `/Library` 下 20+ 个关键目录（`Application Support`, `Caches`, `Containers`, `Group Containers`, `Preferences`, `Saved Application State`, `HTTPStorages`, `Logs`, `LaunchAgents` 等），基于 Bundle ID 衍生前缀、名称变体及安全黑名单精准匹配应用残留文件。
