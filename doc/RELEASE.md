## 🚀 v1.2.0 (Latest) — 2026-08-18

### 🔤 1. 屏幕文字与二维码识别 (Vision OCR & Barcode Recognition)
* **系统原生深度学习识别引擎**：
  * 基于 Apple `Vision` 框架深度学习神经网络模型 (`VNRecognizeTextRequest` + `VNDetectBarcodesRequest`)，零第三方二进制依赖，极低内存与 CPU 开销。
  * **中英混排与生僻字支持**：配置候选语言集 `["zh-Hans", "zh-Hant", "en-US", "ja", "ko"]` 并启用 `automaticallyDetectsLanguage = true`，彻底杜绝特殊符号与汉字识别乱码。
* **二维码 / 条形码并发解析**：
  * 支持同时检测并解析选区内包含的二维码、条形码内容（URL、序列号、支付码等）。
* **URL 智能提取与浏览器直达**：
  * 自动正则识别文本中的网址链接，并在结果卡片中提供 **Safari 一键打开** 快捷按钮。

### 📋 2. 识别历史归档与管理 (OCR History Manager)
* **本地轻量持久化**：
  * 数据自动以 JSON 格式存储于 `~/Library/Application Support/CalmBar/ocr_history.json`，原子安全落盘。
* **独立管理窗口与多维筛选**：
  * 提供独立历史管理窗口，支持实时关键字搜索、分类筛选（全部 / 文本 / 二维码条码）、单项复制反馈、单项删除与一键清空全部。
* **容量上限控制**：
  * 偏好设置中支持设定历史记录保留条数（50 / 100 / 200 / 500 条），超出后自动以 LRU 逻辑截断。

### 🪟 3. 高颜值毛玻璃悬浮预览窗口 (Floating Preview Window)
* **舒展大尺寸排版**：
  * 悬浮面板宽度达 `480px`，文本区域最小高度 `140px`、最大可展开至 `260px`，字号 `13pt` 搭配 `4pt` 行间距，多段落大文本舒适预览。
* **单一干净按钮与操作流**：
  * 彻底隐藏 macOS 原生失效红绿灯，右上角提供统一关闭按钮，底部提供 **「一键复制」** 与 **「删除记录」** 快捷操作。
* **自动倒计时消失与时间定制**：
  * 支持在偏好设置中开启/关闭自动倒计时消失，并支持自由调节延迟时间（`5s` / `8s` / `10s` / `15s` / `30s` / `60s`）。

### ⚡ 4. 交互体验细节优化
* **选区截图防遮挡**：
  * 点击「截屏识字」或打开「历史记录」时，菜单栏主面板立即平滑自动收起，消除对屏幕目标内容的视觉遮挡。

## 🚀 v1.1.0 — 2026-08-18

### 🔋 1. 电池健康管理与充电上限控制 (Battery Charge Limit)
* **SMC 硬件级充电阻断**：
  * 通过底层 AppleSMC 寄存器（`CHTE` / `CH0C`）实现硬件级充电截止，达到目标电量（默认 80%）后切断流入电池电流，转由电源适配器直接给主板**旁路供电**。
  * 支持配置目标上限（60% ~ 95% 自由设定）。
* **回差巡航模式 (Sailing Mode)**：
  * 解决临界点高频微充微放问题，支持自定义回差区间（如 75% ~ 80%）。
  * 电池在上限保持旁路供电，自然耗电跌破下限（75%）时再启动涓流补电。
* **快捷临时满电 (Top Up)** 与 **强制放电 (Force Discharge)**：
  * 支持一键开启“临时充至 100%”，充满一次后自动恢复 80% 养护模式。
  * 支持自动放电功能（通过切断适配器输入使用电池供电消耗至目标值）。
* **安全复位机制 (Fail-Safe)**：
  * 应用退出、系统重启或特权助手连接断开时，自动将 SMC 寄存器复位为系统默认托管，绝不影响正常充电。

### 🎵 2. Apple Music 启动拦截与重定向 (noTunes)
* **防误触秒级拦截**：监听系统工作区进程事件，毫秒级终止由蓝牙耳机连接、键盘媒体键触碰等意外拉起的 `com.apple.Music` 或 `iTunes`。
* **替代启动**：支持拦截后无缝拉起指定第三方音乐播放器（如 Spotify、网易云、QQ 音乐等）或打开指定 Web 播放页面。

### ☕ 3. 系统防休眠与协同软件防离开 (Caffeine / Keep Awake)
* **原生 IOKit 临时断言**：注册 `kIOPMAssertPreventUserIdleDisplaySleep`，安全阻止长耗时任务（编译、渲染、下载）期间系统意外黑屏休眠。
* **多档定时器**：支持无限期保持清醒，以及 5m / 15m / 30m / 1h / 2h / 5h 多档快捷倒计时。
* **办公软件防离开 (Activity Simulator)**：系统空闲时自动向事件总线发送像素级微小微动，防止 Teams、Slack、飞书、钉钉等协同办公软件被误判为「离开」状态。
* **持久化与生命周期优化**：应用退出时仅释放系统断言，保留用户的持久化开启状态，重启后自动恢复。

### 🛡️ 4. 软件去隔离与代码签名修复 (Gatekeeper Unlocker)
* **一键去除隔离属性**：递归剥离下载应用的 `com.apple.quarantine` 扩展属性。
* **Ad-hoc 深度重签名**：执行 `codesign --force --deep -s -`，彻底解决 macOS 提示“应用程序已损坏，无法打开”的拦截问题。

### 🎨 5. 偏好设置动态展开胶囊 Tab 栏 (Dynamic Capsule Tab Bar)
* **呼吸感极简布局**：未选中项仅展示图标，避免视觉拥挤；选中项动态横向拉长形成强调色高亮胶囊，并平滑滑出标题文字。
* **Apple 原生弹簧动画**：搭载 `.spring(response: 0.3, dampingFraction: 0.7)` 弹性动效，搭配文字 `.transition(.opacity.combined(with: .scale(scale: 0.9)))`，切换流畅丝滑。

### ⚙️ 6. 任务栏面板高度自由点选与自适应
* **面板项目自由定制**：在「偏好设置 -> 通用设置」中，支持对除风扇外的所有快捷功能模块（硬件仪表盘、菜单栏收纳、鼠标滚轮反转、Apple Music 拦截、防休眠、充电管理、应用授权）自由勾选显示或隐藏。
* **动态自适应布局**：面板自动重排并动态计算 Divider 分隔线，隐藏全部快捷项时自动隐藏外框，高度自适应紧凑缩放。

### 🛠️ 7. 细节优化与 Bug 修复
* **面板文案精炼防截断**：全面重构任务栏面板中的主副标题与状态文本，彻底消除有限面板宽度下的 `...` 省略号截断问题。
* **电池温度 DeciKelvin 换算修正**：严格按 Apple IOKit 规范修正 `AppleSmartBattery` 温度读取公式（`DeciKelvin / 10.0 - 273.15`），提供高精度的摄氏度读数。

## 🌿 v1.0.0 (Initial Release) — 2026-08-10

### 💨 1. 硬件温控与风扇调控 (AirPulse)
* **实时硬件传感器读取**：毫秒级采集 Apple Silicon SoC（CPU/GPU 核心）、电池温度及双风扇转速（RPM）。
* **三档调控模式**：
  * **自动模式 (Auto)**：恢复 macOS 系统原生 SMC 散热策略。
  * **智能模式 (Smart)**：基于自定义温度阈值区间的智能动态加速曲线（线性插值 + 防抖平滑）。
  * **手动模式 (Manual)**：提供滑块供用户直接锁定指定 RPM 转速。
* **双风扇独立/联动控制**：支持左右风扇一键联动或分别设定不同转速。
* **过热安全阶梯防护 (Safety Policy)**：高温（75°C+）、紧急（90°C+）及极端危险（98°C+）阶梯式过热强制风扇提速保护。

### 📥 2. 菜单栏图标多级收纳 (Hidden Bar)
* **多分区收纳管理**：
  * **常驻显示区**：核心图标始终可见。
  * **折叠隐藏区**：低频图标通过分隔符一键折叠或展开。
  * **永久隐藏区**：完全移出菜单栏可见区域。
* **智能自动化**：支持全局热键展开/收纳、展开后闲置指定秒数自动收纳。

### 🖱️ 3. 输入设备滚动方向解耦 (Scroll Reverser)
* **独立滚动手势反转**：彻底解决 macOS 下外接普通鼠标滚轮与 MacBook 触控板自然滚动方向绑定的痛点。
* **外接鼠标反转**：鼠标滚轮恢复传统 Windows 方向，同时触控板保持原生多指滑动与惯性手势体验。
* **轴向独立配置**：支持垂直与水平方向独立开启/关闭反转。

## 🏗️ 架构与系统兼容性

* **开发语言**：Swift 6 (Strict Concurrency Checking)
* **界面框架**：SwiftUI + AppKit (原生适配 macOS 现代设计规范与 Liquid Motion 交互)
* **硬件驱动层**：IOKit + AppleSMCClient Direct Protocol
* **特权服务**：`SMJobBless` / Privileged Helper Tool (`com.chaoeng.CalmBar.helper`)
* **系统支持**：macOS 14.0 (Sonoma) 及以上，完美原生适配 Apple Silicon (M1 / M2 / M3 / M4 系列) 与 Intel 架构 Mac。
