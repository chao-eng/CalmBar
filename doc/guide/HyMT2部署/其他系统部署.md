# Hy-MT2 跨平台服务端部署指南 (Linux / Docker / NAS / Windows)

本项目支持通过 **Docker 容器化** 或 **llama-server (llama.cpp)** 在各类 Linux 服务器、家庭 NAS (群晖 / QNAP / Unraid)、Windows (WSL2) 以及局域网私有云上高速部署 **Hy-MT2 GGUF 量化模型**，提供标准 OpenAI 兼容 HTTP 翻译接口供 CalmBar 远程/局域网接入。

---

## 📥 1. 模型下载

Hy-MT2 官方提供了针对端侧和服务器优化的各级量化 GGUF 模型：

- **ModelScope (魔搭社区 国内高速下载)**：
  👉 [https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B-GGUF](https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B-GGUF)

推荐量化版本：
- `Hy-MT2-1.8B-Q4_K_M.gguf`：标准平衡量化（约 1.2GB~1.5GB 内存）。

下载示例（以 Linux 终端为例）：
```bash
mkdir -p /opt/models
cd /opt/models

# 使用 wget 或 curl 从 ModelScope 下载
wget -O Hy-MT2-1.8B-1.25Bit.gguf https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B-GGUF/resolve/master/Hy-MT2-1.8B-1.25Bit.gguf
```

## 🐳 2. Docker 部署方案 (推荐)

### 方案 A：Docker 单行命令极速启动

```bash
docker run -d \
  --name hy-mt2-server \
  --restart unless-stopped \
  -p 8000:8080 \
  -v /opt/models:/models \
  crpi-a1liy20beodq2bdl.cn-beijing.personal.cr.aliyuncs.com/bujic/llama-server:pr22836 \
  -m /models/Hy-MT2-1.8B-1.25Bit.gguf \
  -c 2048 \
  -t 8 \
  -tb 8 \
  --kv-unified \
  --host 0.0.0.0 \
  --port 8080 \
  --parallel 4 \
  --cont-batching
```

---

### 方案 B：Docker Compose 编排部署

创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  hy-mt2-server:
    image: crpi-a1liy20beodq2bdl.cn-beijing.personal.cr.aliyuncs.com/bujic/llama-server:pr22836
    container_name: hy-mt2-server
    restart: unless-stopped
    ports:
      - "8000:8080"
    volumes:
      - ./models:/models:ro
    command: >
      -m /models/Hy-MT2-1.8B-1.25Bit.gguf
      -c 2048
      -t 8
      -tb 8
      --kv-unified
      --host 0.0.0.0
      --port 8080
      --parallel 4
      --cont-batching
```

启动容器：
```bash
docker compose up -d
```

查看日志与运行状态：
```bash
docker compose logs -f
```

## ⚡ 3. 关键启动参数说明

| 参数 | 推荐值 | 说明 |
| :--- | :--- | :--- |
| `-m` | `/models/Hy-MT2-1.8B-xxx.gguf` | 指定容器内映射的模型文件路径 |
| `-c` | `2048` | 上下文 Context 长度（翻译场景 2048 足够满足长段落） |
| `-t` / `-tb` | `4` ~ `8` | 推理 CPU 线程数（建议配置为机器物理核心数） |
| `--parallel` | `4` | 支持并发请求并发路数 |
| `--cont-batching` | *(开启)* | 连续批处理，提升多请求并发吞吐率 |
| `--host 0.0.0.0` | `0.0.0.0` | 允许局域网外部设备访问 |
| `-ngl` *(仅带 GPU 机型)* | `99` | 将所有层 Offload 加载进 NVIDIA GPU 显存加速 |

## ⚙️ 4. 在 CalmBar 中配置接入

部署就绪后，在 Mac 上的 **CalmBar 偏好设置** $\to$ **【智能翻译】** 中填入服务器地址：

| 配置项 | 示例配置值 | 说明 |
| :--- | :--- | :--- |
| **API 基础地址 (Base URL)** |  `http://<局域网IP>:8000/v1`或 `http://127.0.0.1:8000/v1` | 部署机器的 IP 与端口，末尾加上 `/v1` |
| **模型名称 (Model)** | `Hy-MT2` 或 `Hy-MT2-1.8B-1.25Bit` | 模型别名 |
| **API Key** | *(留空)* | 内网自建服务无需鉴权 |
| **默认目标语言** | `中文 (zh)` | 支持中/英/藏/维/粤/蒙等 38 种语言 |

点击 **【测试连接】** 按钮，验证网络连通性。
