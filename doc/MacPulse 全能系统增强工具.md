# 项目需求文档 (PRD)：MacPulse 全能系统增强工具

## 1. 项目概述与目标

### 1.1 项目背景
macOS 原生体验虽然优秀，但在多项日常细节上存在割裂：
* 高负载散热策略滞后（撞温度墙才大幅提速）。
* 菜单栏图标杂乱无序且刘海屏易遮挡图标。
* 外接传统鼠标与触控板的全局自然滚动设置互相绑定，无法独立配置。

### 1.2 项目愿景
本项目旨在通过 **Swift + SwiftUI** 技术栈，将 **AirPulse（硬件温控）**、**Hidden Bar（菜单栏收纳）** 与 **Scroll Reverser（滚动手势解耦）** 深度整合，打造一款轻量、极简且原生的高性能 macOS 菜单栏综合增强套件。

---

## 2. 核心功能需求

### 2.1 模块一：硬件监控与风扇温控 (Thermal & Fan Control)
* **实时状态读取**：
  * 读取 SoC（CPU/GPU）核心温度、电池温度及环境温度传感器数值。
  * 读取当前风扇的实际转速（RPM）及硬件允许的最小/最大转速边界（`F0Mn` / `F0Mx`）。
* **三档调控模式**：
  * **自动模式 (Auto)**：重置为系统默认托管（SMC 官方策略）。
  * **智能温控 (Smart)**：支持基于温度阈值配置的动态加速曲线（线性插值 + 防抖平滑），支持自定义起始加速温度（如 45°C）与满速温度（如 80°C）。
  * **自定义模式 (Manual)**：提供滑块供用户直接锁定指定 RPM 转速或百分比。
* **多风扇策略**：双风扇机型支持“独立分别控制”与“左右风扇联动调速”。

### 2.2 模块二：菜单栏图标收纳管理 (Menu Bar Organizer)
* **多级分区收纳**：
  * **常驻显示区**：始终展示的核心状态项。
  * **折叠隐藏区**：通过可移动的分隔标记收纳低频图标，点击箭头展开/折叠。
  * **永久隐藏区**：完全移出可见范围的图标区域。
* **交互与自动化**：
  * 支持全局快捷键切换菜单栏展开/收纳状态。
  * 展开后支持配置“无操作 N 秒后自动折叠”。

### 2.3 模块三：输入设备滚动方向解耦 (Scroll Reverser)
* **设备级独立配置**：
  * **触控板**：保持原生自然滚动（或反转）。
  * **外接鼠标**：强制反转垂直方向（Y 轴）以恢复传统滚轮习惯，不影响触控板手势。
* **轴向独立控制**：支持分别反转垂直滚动与水平滚动（X 轴）。
* **原生手势兼容**：保留触控板的双指惯性滑动与缩放手势，无明显输入延迟。

### 2.4 模块四：Apple Music 拦截与替代 (noTunes)
* **静默拦截防御**：监听系统应用启动事件，瞬间强制终止 `com.apple.Music` 与 `com.apple.iTunes` 的自动唤起（如蓝牙耳机重连、媒体按键触碰等场景）。
* **无缝替代启动 (Replacement)**：支持配置第三方音乐 App 或 Web 网页播放器无缝替代唤起。

### 2.5 模块五：系统防休眠与办公软件防离开 (Caffeine / Keep Awake)
* **IOKit 电源断言**：通过 `kIOPMAssertPreventUserIdleDisplaySleep` 阻止系统与显示器意外休眠，保障编译、渲染与大文件传输等长耗时任务。
* **定时与倒计时**：支持无限期保持清醒及 5m/10m/15m/30m/1h/2h/5h 多档倒计时。
* **办公软件防离开 (Activity Simulator)**：读取系统真实空闲时间，闲置时自动原地发送轻量 HID 事件，防止 Microsoft Teams、Slack、飞书等软件误判离开状态。
* **会话与电源生命周期**：多用户注销/锁屏时自动挂起，手动睡眠时自动关闭，退出时安全释放所有断言。

### 2.6 模块六：未签名与损坏应用去隔离 (Gatekeeper Unlocker)
* **拖拽一键解除隔离**：递归移除 `com.apple.quarantine` 属性。
* **Ad-hoc 深度重签名**：修复签名损坏或修改过的应用。
* **特权助手提权**：免终端无密码处理受系统保护的应用。

### 2.7 模块七：充电管理与电池上限 (Battery Charge Limit)
* **SMC 硬件级充电阻断**：向 SMC 寄存器（`CH0C` / `CHTE`）写入阻断信号，达到目标阈值（默认 80%）后切断流入电池电流，转由电源适配器直接给主板旁路供电。
* **回差巡航模式 (Sailing Mode)**：支持设置 75%~80% 巡航区间，电池自然耗电至下限时才恢复涓流充电，防止临界点高频微充微放。
* **临时充至 100% (Top Up)**：一键临时放开充至满电，充满后自动恢复 80% 限制。
* **电池健康度与指标监控**：实时读取电池健康百分比、循环计数、实时温度与供电功率。
* **安全回退保护 (Fail-Safe)**：软件退出、崩溃或重启时自动恢复系统默认充电逻辑。

### 2.8 模块八：屏幕文字与二维码识别 (Vision OCR & History)
* **原生深度学习识别**：基于 macOS Apple `Vision` 框架深度学习模型（`VNRecognizeTextRequest` + `VNDetectBarcodesRequest`），零第三方二进制依赖，极速无感。
* **多语言与混排支持**：支持简体中文、繁体中文、英语、日语、韩语自动识别与代码/符号混排识别，彻底消除乱码。
* **选区交互与防遮挡**：触发截屏时自动平滑收起菜单栏面板，无遮挡框选屏幕任意区域。
* **URL 智能直达**：自动正则提取文本中的网址链接，支持一键调起 Safari 打开。
* **历史持久化管理**：本地 JSON 原子存储，支持搜索过滤、分类筛选、单项删除、一键清空与 50~500 条容量上限控制。
* **悬浮预览与自动消失**：高对比度毛玻璃大尺寸结果预览窗，支持一键复制、直接删除，并可在偏好设置中自由配置自动倒计时消失（5s~60s）或常驻。

## 3. 技术架构与系统权限要求

### 3.1 技术栈选型
* **开发语言**：Swift 6+
* **UI 框架**：SwiftUI + AppKit（混合使用以支持原生状态栏精细控制）
* **事件拦截层**：`CoreGraphics` / `CGEventTap`
* **硬件驱动通信**：`IOKit`（与 `AppleSMCClient` 驱动交互）

### 3.2 权限与系统要求
* **辅助功能权限 (Accessibility Permissions)**：用于 `CGEventTap` 拦截并动态翻转鼠标滚轮事件。
* **SMC 通信特权**：免沙盒运行（Non-Sandboxed）或集成带有 Root 权限的 Privileged Helper Tool 用于读写 SMC 寄存器。
* **系统支持**：macOS 13.0 (Ventura) 及以上，原生适配 Apple Silicon（M1/M2/M3/M4 系列）及 Intel 芯片机型。

---

## 4. 非功能性需求

* **极低资源开销**：常驻后台时 CPU 占用 < 0.5%，静态内存占用控制在 40MB 以内。
* **快速冷启动**：登录项自启动时在 200ms 内完成托盘加载与驱动初始化。
* **零侵入与容错**：软件退出或崩溃时，自动将 SMC 风扇控制权交还给 macOS 官方固件（恢复 Auto 模式），避免风扇因软件异常停摆引发过热。

---

## 5. 里程碑与开发计划

* **Phase 1 (底层打通)**：实现 SMC 驱动读写库（Swift 封装）与 CGEventTap 滚动拦截器。
* **Phase 2 (功能集成)**：移植菜单栏收纳分隔符逻辑，整合三套功能的核心业务状态机。
* **Phase 3 (UI 与交互)**：使用 SwiftUI 编写统一的菜单栏弹出面板（Popover）与偏好设置窗口。
* **Phase 4 (优化与发布)**：异常崩溃回退机制、热插拔外设检测与开源 Release 打包。
