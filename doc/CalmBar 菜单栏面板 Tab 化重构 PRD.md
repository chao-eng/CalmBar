## 1. 产品概述

### 1.1 产品背景

当前左键面板 `PopoverContentView` 是一条**单列纵向流**：头部 → 权限横幅 → 仪表 → 风扇调速 → 快捷工具行 → 守护卡网格 → 底栏。随着模块增至 12 个，出现三个结构性问题：

1. **高度失控**。风扇卡片 + 5 张守护卡 + 6 个工具磁贴叠在一起，常规机型已经接近 500pt；再叠加音频/监控/录屏会突破 640pt，小屏 MacBook 上会顶到 Dock。
2. **入口规格不一致**。工具行是「点一下就走」的动作入口（OCR 截图、打开剪贴板、跳设置），守护卡是「就地开关」的配置入口（防休眠、充电上限），两类东西混排在同一视觉流里，认知成本高。
3. **工具行被挤压**。6 个磁贴挤在 320pt 单行 HStack 里，每个约 47pt，图标 15pt、标签 10.5pt，已经无法再加第 7 个。

图一给出的解法是「图标分区栏 + 单分区内容」，图二给出的解法是「图标网格收纳入口」。结合近期规划（每应用音量、系统监控），本方案把面板定为**五分区结构**：

> **能就地改的按域分开（温控 / 守护 / 声音），要跳走的进工具，只读指标进监控。**

其中「监控」「声音」在本版本先冻结位置、图标、尺寸与路由契约，模块上线即启用，面板骨架不再改动。

### 1.2 第一性原则分析

> 回到本质：用户点开菜单栏图标的那一秒，只想知道两件事——**「我的 Mac 现在怎么样、我要不要立刻调一下」** 和 **「我要去做那件事，入口在哪」**。

1. **本质需求**：把面板从「功能流水账」拆成「看/调」与「去做」两类心智。
2. **必要条件**：
   - 分区切换必须零思考成本（固定 5 个分区，图标 + 选中态文字，一次点击即达）。
   - 分区内容必须与操作语义一致：温控/守护/声音三个就地分区只有能当场见效的控件；工具分区只有一次性入口；监控分区只有只读指标。
   - 每个模块在面板中**只有唯一主入口**，不重复出现。
3. **硬约束**：
   - 面板宽度保持 320pt，分区栏必须在一行内容纳 5 个入口，不换行、不横向滚动。
   - 分区切换不得引起顶部锚点漂移（面板顶边必须始终贴住菜单栏图标）。
   - 单分区内容不超过 400pt，超出部分内部滚动，面板外框不超过 520pt。
   - 不引入新窗口类型、不改既有快捷键、不改权限流程。

### 1.3 产品目标（含可测指标）

| 目标 | 度量口径 |
|------|----------|
| 打开更快 | 点击图标到首帧可见 ≤ 120ms（含恢复上次分区） |
| 切换跟手 | 点击分区到内容替换 ≤ 80ms；高度变化 ≤ 160ms；无白闪 |
| 面板不跳动 | 同一次展开期间，面板顶边 y 坐标不变（误差 0pt） |
| 不越界 | 面板总高 ∈ [320, 520]pt；任何分区不出现内容被裁切 |
| 工具一眼可辨 | 「工具」分区磁贴 4 列，图标方块 44×44pt，标签 ≤ 5 个汉字且单行不截断 |
| 分区一眼可辨 | 分区栏单行容纳 5 个入口（未选中 40pt / 选中 84pt），不换行、不横向滚动；内容区首行必须出现当前分区名称 |
| 就地分区当场见效 | 「温控」「守护」「声音」任一控件的改动在 1s 内反映到系统或读数 |
| 预留分区零改动接入 | 监控/声音模块上线时，只允许改动数据源与分区内容视图，不得改动分区栏、面板尺寸与路由结构 |
| 零配置可用 | 全新安装首次打开即呈现「温控」分区，无需任何设置 |
| 状态可续 | 关闭面板再打开，分区与滚动位置恢复；退出重启后分区恢复 |
| 键盘可达 | ⌘1~⌘5 依次切换温控/守护/工具/监控/声音；VoiceOver 可朗读分区名与选中态 |

### 1.4 系统范围与组件定义表

| 组件 | 现状 | 本方案改动 |
|------|------|-----------|
| `PopoverContentView` | 单列 VStack，全量直出 | 拆为 `PopoverRootView` + `PopoverTabBar` + `ThermalTabView` + `GuardianTabView` + `ToolsTabView` +（预留 `MonitorTabView`、`AudioTabView`） |
| `StatusBarManager` | 固定 `contentRect` 320×380，依赖 `fittingSize` | 保留定位逻辑；新增「按分区高度」重设 frame，顶边固定 |
| `AppSettings` | 12 个 `popoverShow*` 键 | 语义不变，新增 `popoverSelectedTab`；分区归属由代码常量表定义 |
| `GeneralSettingsTab` | 单组「任务栏左键面板显示项目」 | 拆为「温控与风扇」「常驻守护」「工具入口」三个 GroupBox，键不变 |
| `SettingsTab` / `SettingsCategory` | 14 个 Tab | 不改结构，仅同步分组说明文案 |
| `CommandCenter` | 内置命令 | 可选追加「打开温控 / 守护 / 工具 / 监控 / 声音分区」五条命令 |
| `FeatureID` / 各 Feature | 12 个 | 不改；分区归属集中登记在 `PopoverTabRoute` 常量表 |

### 1.5 明确不做（Non-goals）

- 不做可拖拽重排磁贴、不做用户自定义分区（v1 分区集合为固定 5 个：温控 / 守护 / 工具 / 监控 / 声音）。
- 不做面板横向加宽、不做分栏（SplitView）。
- 不做面板内新增搜索框（搜索仍由命令面板承担）。
- 不做分区数量随模块开关动态增减（分区是否出现在栏中由构建能力决定，见 BR-07）。
- 未上线模块**不做「敬请期待」空壳分区**，避免死入口；上线即出现（见 BR-34）。
- 不做温控分区内的数值历史曲线（趋势归「监控」分区/独立窗口）。
- 不改动右击菜单栏打开偏好设置、⌥⌘K 命令面板、⌥⌘H 菜单收纳等既有快捷键。

## 3. 详细用例规格说明

### UC-U01 打开面板并恢复上次分区

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-U01 |
| **参与者** | 用户、键盘用户 |
| **优先级** | 高 |
| **前置条件** | App 已运行，状态栏图标可见；`popoverSelectedTab` 有值或为空 |
| **后置条件** | 面板展开，顶边贴住图标；当前分区等于上次分区（或回退到「温控」） |
| **基本事件流** | 1. 用户左键点击状态栏图标<br>2. 系统读取 `popoverSelectedTab`，为空则取 `thermal`<br>3. 系统校验该分区是否可用（见 BR-08），不可用则回退 `thermal` 并记一次回退原因<br>4. 系统按该分区自然内容高度计算面板高度并定位（顶边固定）<br>5. 系统渲染分区栏与分区内容<br>6. 系统执行一次 `PermissionManager.refreshAll()`（仅此一次）<br>7. 面板获得键盘焦点，开始监听外部点击关闭 |
| **备选事件流** | 1a. 上次分区内容为空（模块全关）：正常打开并展示该分区空状态（BR-09）<br>2a. 上次分区在本次版本中被移除（如监控分区未启用）：回退 `thermal`，不提示<br>3a. 无 SMC 驱动 / 权限缺失：仍正常打开，对应影响域的分区顶部展示横幅（UC-U06）<br>4a. 命令面板或设置窗正在前置显示：先收起它们再展开面板（沿用既有互斥） |
| **业务规则** | BR-01：面板宽度固定 320pt<br>BR-02：面板顶边 y 恒等于 `statusButton.minY - 4`<br>BR-03：面板总高 = 160（外框装修，含 28 外边距 + 24 头部 + 30 分区栏 + 32 分区标题 + 18 底栏 + 28 间距）+ 内容视口，视口 ∈ [200, 360]，总高 ∈ [360, 520]<br>BR-04：分区读取在任何异步任务之前完成，避免首帧闪到「温控」<br>BR-05：`refreshAll()` 只在面板打开时执行一次，切换分区不再触发 |
| **接口说明** | `StatusBarManager.showPopover(resumeTab: Bool = true)`；`AppSettings.popoverSelectedTab` |

### UC-U02 切换分区（点击 / 快捷键）

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-U02 |
| **参与者** | 用户、键盘用户 |
| **优先级** | 高 |
| **前置条件** | 面板已展开 |
| **后置条件** | 主体区替换为目标分区内容；面板顶边不变；分区值已持久化 |
| **基本事件流** | 1. 用户点击分区栏中的「工具」（或按 ⌘3）<br>2. 系统把当前拖拽中的控件判定为「已提交最后一次值」（见 BR-12）<br>3. 系统切换 `tab` 状态，内容区以淡入替换（80ms）<br>4. 系统按目标分区高度重设面板 frame，顶边固定（≤160ms）<br>5. 系统写回 `popoverSelectedTab`<br>6. 系统把内容滚动位置复位到该分区上次记录的位置（首次为顶部） |
| **备选事件流** | 1a. 用户正在拖动就地分区滑杆：本次点击分区栏不生效，需先松手（BR-12）<br>2a. 用户重复点击已选中分区：不触发重绘，仅把滚动位置回到顶部<br>3a. 高度重算期间收到外部点击：关闭优先，取消高度动画（BR-14）<br>4a. 开启「减弱动态效果」：跳过高度动画，直接切换（BR-13） |
| **业务规则** | BR-06：分区切换不重建业务数据源，只切换视图，禁止在切换时重新发起采样/刷新<br>BR-07：分区栏固定展示「当前构建已启用的分区」，不因模块开关增减；预留分区上线即出现<br>BR-10：快捷键 ⌘1 温控、⌘2 守护、⌘3 工具、⌘4 监控、⌘5 声音（未启用分区跳过，不占位）<br>BR-11：分区栏在拖动控件期间整体禁用（透明度 0.5）<br>BR-12：切换前必须结束在途拖拽手势，滑杆值以最后一次已提交值写入 |
| **接口说明** | `PopoverRootView.select(_ tab: PopoverTab)`；`StatusBarManager.resizePanel(to: PopoverTab)` |

### UC-U03 在就地分区（温控 / 守护 / 声音）就地修改配置

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-U03 |
| **参与者** | 用户 |
| **优先级** | 高 |

### 4.6 线程模型与并发约束

面板本身全部在 **MainActor** 上运行，不新增线程。并发风险集中为「时序」而非「线程」，规则如下：

```
  MainActor（唯一执行线程）
  ├─ 状态：tab / 滚动位置 / 高度动画 token
  ├─ 数据源：AppSettings / FeatureManager / 各 Manager（均为 @MainActor 单例）
  └─ 系统副作用：打开窗口、截图、硬件写入（同步或异步回调后回主线程）

  非面板线程（既有）：
  ├─ ThermalMonitor 采样回调 → DispatchQueue.main
  ├─ HelperClient XPC 回调 → DispatchQueue.main
  └─ LaunchManager 检测回调 → DispatchQueue.main
```

**不可逆顺序**：
1. 收起面板 → 再执行工具动作（禁止先开窗再收起）。
2. 结束拖拽 → 提交值 → 再切换分区。
3. 测量高度 → 再显示面板（禁止先显示再测量导致一帧跳动）。

| BR-01 | 面板宽度固定 320pt，不随分区变化 |

| BR-12 | 切换分区前必须结束在途拖拽，滑杆值以最后一次已提交值为准 |

| BR-20 | 单个模块在面板中只允许一个主入口，禁止跨分区重复出现 |
| BR-21 | 磁贴角标只表达计数（剪贴板条数）或异常（自启崩溃数），不叠加其他状态 |
| BR-22 | 磁贴标签 ≤ 5 个汉字、10pt、单行不截断；超长必须在路由表改名而非缩字号 |
| BR-23 | `popoverShow*` 键语义不变，仅重新分组展示，不做键重命名与数据迁移 |
| BR-24 | 隐藏面板项只影响面板呈现，不改变 Feature 的运行状态 |
| BR-25 | 权限横幅按影响域归属分区：特权助手→温控；辅助功能→守护；屏幕录制→工具；音频采集→声音 |
| BR-26 | 同一权限问题全局只出现一条横幅，禁止跨分区重复放置 |
| BR-27 | 权限状态在面板打开时刷新一次，切换分区不重复刷新 |
| BR-28 | 分区每次切换即写入 `popoverSelectedTab`，不等面板关闭 |
| BR-29 | 收起时取消在途动画与高度重算，并保存分区状态 |

### 5.7 色彩与字体

- 字体：全部沿用系统字体（`system(size:weight:design:)`），不引入自定义字体。
- 强调色：`Color.accentColor`（跟随系统），不对分区栏做额外品牌色。
- 磁贴渐变：直接复用 `SettingsTab.gradientColors`，保证与偏好设置侧栏图标一致（**唯一真源**）。
- 语义色：正常 `secondary`；警示 `orange`；异常 `red`；运行 `accentColor`。禁止用红/绿表达「开关状态」。

### 5.8 动效规范

| 场景 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 分区内容替换 | 80ms | `easeOut` | 淡入（opacity 0→1）+ 2pt 上移，禁止横向滑动 |
| 面板高度变化 | 160ms | `easeInOut` | 顶边固定，仅底边位移；无缩放 |
| 分区胶囊选中态 | 120ms | `easeOut` | 宽度 40pt ↔ 84pt 过渡，文字淡入；相邻胶囊随布局在同一 120ms 内平滑重排，**禁止额外的 `offset` / 横向滑动动画** |
| 磁贴 hover | 100ms | `easeOut` | 底色 `primary 4%→8%`，描边 0.5pt 变化，**不做位移** |
| 磁贴按下 | 60ms | — | 缩放到 0.97 后回弹 |
| 声音行增删（预留） | 120ms | `easeOut` | 差集插入/移除；拖拽中的行不参与动画 |

- 开启「减弱动态效果」：全部动效退化为瞬时切换（BR-13）。
- 分区栏作为单一布局容器：选中态宽度变化驱动整组重排，相邻胶囊的位移由布局动画产生，不叠加独立位移动画；整组总宽恒为 268pt 并保持居中，因此不产生换行或横向滚动。
- 面板高度变化期间禁止同时做内容淡入以外的动画，避免掉帧。

| 写入失败 | 卡内单行：「未生效：{原因}」 | 自动回滚值 |

### 5.10 无障碍与键盘

- 分区栏容器 `accessibilityLabel("面板分区")`；每个胶囊 `accessibilityLabel("{名称}，{N} 个分区中第 M 个")`，选中态追加「已选中」。
- VoiceOver 朗读顺序：头部状态 → 分区栏 → 分区名与说明 → 当前分区内容 → 底栏。
- 键盘：⌘1 温控、⌘2 守护、⌘3 工具、⌘4 监控、⌘5 声音；`Esc` 关闭；Tab 键遍历当前分区内可聚焦控件；磁贴支持 Space 触发。
- 焦点环使用系统默认，不用自绘描边；磁贴 `focusable(false)` 仅用于抑制鼠标点击焦点环，键盘可达路径由分区容器统一管理。
- 分区栏胶囊与风扇模式分段控件 `focusable(false)` + `focusEffectDisabled()`，抑制默认选中态的蓝色焦点方框；两处键盘可达由窗口层 ⌘1–⌘5 / ←→ 与鼠标点击保证，其余控件保留系统焦点环。
- 纯图标胶囊必须同时具备 `help` tooltip 与 VoiceOver 标签，禁止只靠图标传达语义（BR-33 / BR-36）。
- 对比度：文字与底材对比 ≥ 4.5:1；仅图标表达状态时必须同时提供文字或 `help`。

## 6. 非功能需求

### 6.1 性能

| 指标 | 口径 |
|------|------|
| 打开耗时 | 点击 → 首帧 ≤ 120ms（M1 机型，冷启动后第二次点击） |
| 切换耗时 | 点击分区 → 内容替换 ≤ 80ms；frame 变化 ≤ 160ms（Spike 2 实测 139–155ms，含动画 completion 回调） |
| 帧率 | 切换与滚动期间无掉帧（Instruments 无 hitch > 16ms） |
| 内存 | 重构后常驻内存增量 ≤ 0（仅新增 3 个轻量分区视图结构，不缓存图片；监控/声音上线前不构建） |
| CPU | 面板展开且静止时 CPU ≤ 0.5%；分区切换不引发新采样 |
| 定时器 | 不新增任何 Timer；角标数据来自既有 @Published 属性 |

### 6.2 兼容性

- 部署目标 macOS 14.0（与 `Package.swift` 一致）。
- 兼容有风扇机型 / 无风扇机型：无风扇时温控分区不出现调速器，展示纯监控说明条。
- 兼容无电池机型：充电保护卡不出现（沿用现有 `batteryMonitor.hasBattery` 判断）。
- 兼容深浅色、增强对比度、减弱动态效果、放大文字（系统辅助功能）。
- 兼容多显示器与菜单栏自动隐藏：沿用现有定位与夹取逻辑。
- 窄屏（1280×800 可见区）：面板总高 ≤ 520，确保不覆盖 Dock。
- 面板内滚动：内容超视口时启用系统 `ScrollView`（视口 400pt），偏移夹取到 `[0, 内容高 − 视口高]`（Spike 3 已验证 600/400、上下越界均正确夹取）；滚动事件由面板消费，不向桌面穿透（结构探针计数为 0，真实穿透待手测）。

### 6.3 安全与隐私

- 不新增数据采集与上报；分区选择仅存本地 `UserDefaults`。
- 工具动作沿用既有权限申请与 TCC 流程，不在面板内做任何静默授权。
- 面板内容不含用户隐私数据（剪贴板只显示条数，不显示内容）。

### 6.4 可靠性

- 分区状态损坏（非法字符串）→ 回退 `thermal`，不崩溃。
- `popoverShow*` 全部为 false → 各分区均展示空状态，面板仍可打开并进入偏好设置。
- 高度计算异常（内容高度为 0）→ 使用兜底高度 360pt。
- 视图切换不持有强引用循环（`@State`/`@ObservedObject` 单例）。
- 崩溃恢复：冷启动后分区恢复为上次选择。

## 8. 易用性设计原则

### 8.1 零配置快速开始

- 首次打开默认「温控」分区，直接看到温度与风扇，**不需要先做任何设置**；守护开关集中在「守护」分区。
- 工具分区无需配置即可用；所有 12 个模块的默认可见性保持不变（不因重构而重置用户勾选）。

### 8.2 用户可见配置 ≤ 4 项

| 层级 | 可见配置 |
|------|----------|
| 温控分区内 | 风扇模式、联动开关、转速滑杆（同一张卡内） |
| 守护分区内 | 5 个一键开关（单击即改，不展开二级配置） |
| 工具分区内 | 仅「自定义」一个跳转入口 |
| 偏好设置「通用设置」 | 温控 / 守护 / 工具 三组显示项（三组勾选） |
| 监控 / 声音（Phase 2） | 分区内不设额外配置，深度设置跳对应模块设置页 |

### 8.3 全链路无主动打扰

- 分区切换不弹窗、不播报。
- 写入失败只在卡内一行提示，不弹窗。
- 权限问题只在影响域所在分区（温控/守护/工具/声音）内一条横幅，其他分区只留头部警示图标。
- 工具执行失败在目标窗口提示，不在面板二次弹窗。

### 8.4 小白语言规范（术语 → 人话）

| 禁止出现在用户界面 | 替换为 |
|--------------------|--------|
| Popover / 弹出面板 | 面板（或直接不写） |
| Dashboard / 仪表盘 | 温控分区 |
| Tab / 标签页 | 分区（仅无障碍标签中可出现「标签页」以兼容系统朗读习惯） |
| Feature / 模块注册 | 功能 |
| Side-effect / 副作用 | 不需要出现 |
| 4×2 Grid | 不出现（界面文案写「快捷入口」） |

### 8.5 状态表达简化

- 分区栏只用「图标 + 名称 + 选中态」，不显示计数气泡（异常以头部警示点表达）。
- 单个守护卡同一时刻只表达一个状态：运行中 / 已停用 / 不可用 / 异常。
- 磁贴角标最多表达一类信息，禁止叠加多个徽标。

### 8.6 一致性检查表（含上游 PRD 口径收敛）

| 检查项 | 结论 |

| 3 | `fittingSize` 与固定高度的冲突 | 中危 | 改为「按分区算高度并显式 setFrame」，不再依赖自动 fitting。**Spike 2 已确认**：`fittingSize` 仅作对照记录，高度由常量驱动 |
| 4 | `ScrollView` 在非激活面板内滚动事件异常 | 中危 | Spike 项 3；退路为分页或不滚动 + 固定高 520。**Spike 3 已部分验证**：程序化偏移、夹取与指示器正常；真实滚轮/惯性待手测 |

#### 11.3a 就地分区准入判定（可执行口径）

模块进入就地分区（温控 / 守护 / 声音），当且仅当以下三条**同时**成立：

1. **交互形态**：主交互是开关、滑杆或分段选择器（不是「点一下就走」）；
2. **生效时延**：改动在 1s 内反映到系统状态或可见读数；
3. **状态可读回**：控件旁能在同一行内读出当前状态（如「80% 旁路」「已收纳」）。

任一条不成立 → 归「工具」分区。`gatekeeper` 虽然是开关语义，但实际动作是打开设置页，因此归工具（第 1 条不成立）。温控与守护的差别只在于内容形态：温控是连续读数与滑杆，守护是离散开关。

### 11.4 小白用户易用性

**用户旅程（首次打开）**

1. 点击菜单栏图标 → 默认落在「温控」→ 看到温度与风扇 → 「这就是我的机器状态」，无需理解任何概念。
2. 想截屏识字 → 点「工具」→ 7 个彩色图标一眼可辨 → 点「截屏识字」，面板自动收起，选区出现。
3. 想临时不睡眠 → 切到「守护」→ 拨动防休眠开关 → 副标题变「无限期」。
4. 找不到某个工具 → 工具分区右上「自定义」→ 通用设置勾选 → 返回即见。
5. 看到「监控」「声音」图标但点进去是正常内容（Phase 2 上线后启用），Phase 1 不出现空壳入口。

**劝退点与处理**

| 潜在劝退点 | 处理 |
|-----------|------|
| 不明白五个分区的差别 | 分区名即语义（温控=看+调、守护=自动守着、工具=做一件事、监控=看趋势、声音=管音量），默认落在温控 |
| 分区栏太窄认不出图标 | 选中项图标 + 中文标签，未选中项纯图标 + tooltip |
| 以为切换分区会丢设置 | 所有值实时写回，切换不影响 |
| 面板高度变化感觉抖动 | 顶边固定 + 160ms 位移 + 内容淡入；减弱动态效果时瞬时 |
| 工具分区空了以为出 bug | 明确空状态 + 一键去勾选 |

**操作成本-收益表**

| 操作 | 成本 | 收益 | 结论 |
|------|------|------|------|
| 点一次分区切换 | 1 次点击 / ⌘1~⌘5 | 从「翻找 12 个模块」变成「按语义看 5 个分区」 | 保留 |
| 从工具分区打开窗口 | 1 次点击（面板自动收起） | 直达目标窗口 | 保留 |
| 到偏好设置勾选可见项 | 3 次点击 | 面板更干净 | 保留但降级为二次入口 |

**三条最高优先级改进**

1. 首次打开默认「温控」，让用户先看到状态，而不是先做选择。
2. 工具分区磁贴保持「图标 + 中文短标签」，不做纯图标。
3. 任何空状态、权限异常、写入失败，都给出「下一步可做什么」的一句话。

### 11.5 结论

- **可行性**：视图层重构，不触碰硬件与权限链路；两项 Spike（分区栏样式、面板高度切换）通过后即可进入 M1。
- **并发**：全部在 MainActor，风险为时序而非线程；三条不可逆顺序 + 10 条 BR 已覆盖。
- **模糊度**：分区判定标准、分区集合、面板高度、记忆策略、权限横幅归属、网格规格均已量化。
- **一致性**：与上游音频/监控/录屏 PRD 的 5 处布局冲突已在 §8.6 明确作废或保留，以本 PRD 为准。
- **建议下一步**：评审本 PRD → 确认 §5.6 尺寸表与 §5.4 磁贴列数 → 执行 Spike 项 1/2/3 → 进入 M1。
