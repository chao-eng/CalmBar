## 1. 产品概述

### 1.1 产品背景

CalmBar 的剪贴板历史目前是一个标准 macOS 独立窗口（`ClipboardHistoryWindowController`），内容为"搜索框 + 分段式筛选（Tab）+ 卡片列表"。用户选中一条历史并复制，至少需要 3 次鼠标动作：**点开窗口 → 在 Tab 间切换 → 点某条卡片上的"复制"按钮**，复制后窗口还需手动关闭或失焦隐藏。对高频"翻旧剪贴板"用户，这是明显的重复成本。

本功能对标 `CommandPaletteKit` 已成熟的"搜索框聚焦 + 方向键选择 + 回车激活"模式，把剪贴板历史变成**纯键盘可操作**的快速面板。注意 CalmBar 是 `.accessory` 应用（`AppDelegate.swift:19` 无 Dock 图标），复制后窗口关闭即回到用户此前的前台应用（或需 `⌘TAB` 一次）；本功能保持"仅复制不自动粘贴"的边界（见 §4.6.1）。

### 1.2 第一性原则分析

> 回到本质：剪贴板历史窗口在这个瞬间真正提供的是——**"把上一步（某条历史）取回并放回剪贴板"这个动作要尽量接近一次击键的成本。**

1. **本质需求**：把"翻历史 → 选中 → 复制 → 关窗"压缩为一个可盲操作的序列（Tab + ↑/↓ + ⏎）。
2. **必要条件**：
   - 键盘能改变筛选（左右）——对应键盘事件处理（R-02）
   - 键盘能移动列表选中态（上下）——对应列表选中模型与滚动（R-04）
   - 回车触发"写入剪贴板 + 关窗"原子操作（R-05/R-06）
   - 选中态跨 Tab / 跨列表变化时保持正确（R-03）
3. **约束**：
   - 不可与搜索框光标移动冲突（打字时方向键语义需分流）
   - 不可破坏既有鼠标操作与窗口失焦隐藏逻辑（`clipboardHideOnBlur`）
   - 不可引入新的权限要求（仅需事件监视，属辅助功能范畴内既有能力，无需额外声明）
   - **复制≠粘贴**：CalmBar 为 `.accessory` 应用，快速复制仅写剪贴板、不自动粘贴、不切焦点；用户以 `⌘V` 完成粘贴（R-08）

### 1.3 产品目标（含可测指标）

| 目标 | 度量口径 |
|------|----------|
| 从打开窗口到完成复制的**键盘操作次数上限** ≤ 4（Tab×n + ↑/↓ + ⏎） | 手动回归：模拟 6 分类 Tab 内任意位置完成复制，统计有效按键 |
| 关闭开关后行为与现状逐位一致 | 回归用例：关闭快速复制后，方向键只移动搜索框光标、回车只提交搜索、无任何选中态 |
| 键盘操作不可被误触发 | 断言：方向键事件仅在窗口为 key window 且开关开启时被消费（可单测纯函数） |
| 不增加启动/监听开销 | 开关关闭时**零**事件监视器注册（按需安装/卸载） |
| 键盘复制正确性可自动回归（评审增补，可测断言） | 单测/UI 测试：快速复制开启下模拟按键序列（Tab×n + ↑/↓ + ⏎），断言 `NSPasteboard` 内容 = 目标项 |
| 键盘路径与鼠标路径一致，不产生重复历史（评审增补） | 回归：键盘复制后等待 >1s（覆盖 0.5s 轮询），历史列表**无重复条目**、`copyCount` 不异常 |

### 1.4 系统范围（含组件定义表）

| 组件 | 现状 | 本功能改动 |
|------|------|-----------|
| `ClipboardHistoryWindowController` | 独立窗口 + show/toggle/close + 失焦隐藏 | 新增 `closeAfterCopy()` 语义（可复用 `close()`）；不改窗口样式 |
| `ClipboardHistoryView` | 搜索框 + `selectedFilter`(segmented) + 卡片列表 + `copiedItemID` 提示 | 引入键盘导航：Tab 左右切换、列表选中态、回车复制；回车成功后复用 `copiedItemID` 反馈并 0.5s 自动关窗 |
| `ClipboardHistoryManager` | 历史存储与 `copyToPasteboard(item:)` | 不改（直接复用写入逻辑） |
| `AppSettings` | `clipboard*` 系列偏好 | 新增 `clipboardQuickCopyEnabled` |
| `ClipboardSettingsTab` | 分组卡片设置 | 「历史窗口与快捷操作」分组内新增开关与说明文案 |
| 键盘事件监视器 | 无（窗口内无监听） | 按需新增 local event monitor（参照 CommandPaletteKit） |

### 评审修订（v1.1 新增 BR） — 键盘模式总开关、回车语义、Esc、copyCount、输入法

> 本小节 v1.1 回填。以下 BR 编号接续 UC-03 的 BR-15（原文档 BR-16~19 在 UC-04 与 §4.5）。

| 修订项 | 回填 |
|--------|------|
| F-07（开关语义） | BR-16a：「快速复制」开关 = **键盘模式总开关**。关闭 → 无 Tab 键切换、无列表键盘选中、回车只提交搜索（与现状逐位一致）。名称沿用"快速复制"，副标题说明含"键盘操作" |
| F-03（搜索框回车分流） | BR-12a：**裁决确定——回车永远 = 复制当前选中项**（只要列表有非空选中）。放弃文本域"提交搜索"语义（该功能可由触摸板/鼠标/点外部取代）。搜索词过滤是"先选中再复制"的辅助手段，不产生独立"提交"动作。须 V-01 Spike 确认本地事件监视器在 `keyDown` 阶段先于文本域消费裸回车 |
| F-06（Esc） | BR-11a：键盘 Esc = 关闭窗口（等效失焦关窗路径）。在剪贴板窗口 key window 时消费裸 Esc（return nil），放行带修饰键的 Esc |
| F-04（copyCount 一致） | BR-13a：快速复制**与现状鼠标复制一致**，不递增 `copyCount`，不新增历史重复项（复制写入即含 `calmbar` 自环标记，被 `shouldIgnore` 识别跳过，BR-20 保障时序） |
| F-10（中文输入法） | BR-12b：中文输入法组词 inline 会话进行中按回车 → 由输入法上屏候选，**快速复制不消费**。检测：事件到达时输入法 inline 会话未提交（`markedText` 非空/`hasMarkedText`），则该回车放行给文本域/输入法 |
| F-02（键盘覆盖范围） | BR-16b：键盘覆盖范围 = Tab 切换 + 列表选择 + 回车复制 + Esc 关闭。卡片上的 翻译/Pin/删除/纯文本 等按钮仍为鼠标操作，键盘不劫持。新增键盘命令不涉及这些按钮 |

### UC-02 键盘浏览历史（左右切 Tab、上下移动选中）

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-02 |
| **用例名称** | 键盘浏览历史 |
| **参与者** | 用户 |
| **优先级** | 高 |
| **前置条件** | 剪贴板窗口已打开；BR-02 成立（快速复制开启）；焦点在窗口内 |
| **后置条件** | 列表存在可见选中项；当前 Tab 记录 |
| **基本事件流** | 1. 用户按 `←`/`→`：在 `ClipboardFilterType` 的 `allCases` 顺序中前后切换选中 Tab（首尾循环）<br>2. 系统重算 `filteredItems`（当前 Tab + 搜索词过滤）<br>3. 若结果非空，选中项置为该列表**第一个**元素；若结果为空，无选中项<br>4. 用户按 `↑`/`↓`：选中项在当前 `filteredItems` 列表内前移/后移一格（边界处钳制，不循环越界）<br>5. 系统滚动列表保证选中项可见 |
| **备选事件流** | 1a. 按 `←`/`→` 时搜索框正被编辑且携带修饰键（Option/Command/Cmd+方向）：放行给文本框做光标/词跳移动，不切 Tab<br>2a. 当前 Tab 无结果：`↑`/`↓` 无效果，选中保持空态<br>3a. 搜索词变化导致结果集变化：选中态重算（见 BR-06） |
| **业务规则** | BR-04：Tab 循环规则——`←` 到首个时再按回到末个，`→` 到末个时再按回到首个（wrap-around）。<br>BR-05：Tab 切换后若新列表非空，选中索引 = 0；若新列表为空，选中 = nil。<br>BR-06：搜索词变更后：若当前选中项仍在结果集内则**保留其选中**；否则选中回退到列表首位（结果集为空则 nil）。<br>BR-07：`↑`/`↓` 移动范围钳制在 `0...count-1`，不循环、不越界。<br>BR-08：上下移动与 Tab 切换后，选中行需通过 `ScrollView` 滚动保持可见（参照 CommandPaletteKit `scrollSelection`）。<br>BR-09：鼠标悬停优先——鼠标移动悬停在某卡片上时，选中态跟随鼠标（hover）；键盘移动后短窗口内抑制 hover 回抢（复刻 CommandPaletteKit `HoverSelectionGate`，建议窗口 0.25s）。<br>BR-10：键盘事件仅在「事件窗口 === 剪贴板窗口」且无文本编辑修饰键时被消费；其它窗口/其它修饰键一律放行。 |

### UC-03 回车快速复制（成功反馈后自动关窗）

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-03 |
| **用例名称** | 回车快速复制并关窗 |
| **参与者** | 用户、系统剪贴板 |
| **优先级** | 高 |
| **前置条件** | UC-02 进行中；存在非空选中项 |
| **后置条件** | 选中条目已写入系统剪贴板；界面展示成功反馈；窗口在 0.5s 后自动关闭 |
| **基本事件流** | 1. 用户按 `⏎`（Return）<br>2. 系统取 `keyboardSelectionID` 对应的完整 `ClipboardItem`<br>3. 系统调用 `ClipboardHistoryManager.copyToPasteboard(item: plainTextOnly: false)` 写入剪贴板（含防自环标记 `calmbar`）<br>4. 系统展示"已复制到剪贴板"成功反馈（视觉，复用现有绿勾文案）<br>5. 0.5s 后系统自动关闭剪贴板窗口（BR-22）<br>6. 用户回到原应用按 `⌘V` 粘贴 |
| **备选事件流** | 1a. 按回车时无选中项：忽略，不复制、不关窗<br>2a. 列表无选中项时回车：无副作用（快速复制开启时不存在独立"提交搜索"语义，见 BR-12a）<br>3a. 写入失败：沿用 `ServiceError` / 窗口状态提示路径，不静默失败（遵守"用户可见失败"原则）；**不**触发成功反馈与自动关窗 |
| **业务规则** | BR-11：回车仅在「存在选中项」时执行复制；否则无副作用。<br>BR-12a：**回车语义定案**——快速复制开启时，剪贴板窗口内回车永远 = 复制当前选中项（只要列表有非空选中）。原文本域 `onSubmit`"提交搜索"职责被取代；搜索词仅作为"先筛选再复制"的辅助手段。关闭快速复制后回车恢复文本域默认行为。详见 §4.6 与 V-01 Spike。<br>BR-13：复制 = `copyToPasteboard(item:plainTextOnly:false)` 保留富文本/图片/文件原始格式，遵循既有类型分发。<br>BR-13a：快速复制与现状鼠标复制一致，不递增 `copyCount`、不产生重复历史。<br>BR-14：复制成功后窗口**延时自动关闭**（默认 0.5s，见 BR-22），无论 `clipboardHideOnBlur` 开关当前值（快速复制本身就是显式隐藏意图）。<br>BR-15：复制、成功反馈、自动关窗之间为原子操作序列——写入剪贴板→立即显示反馈→0.5s 后 `close()`，均在主循环完成，不可被新键盘事件中断。<br>BR-22：**成功反馈与自动关窗（v1.2 定案）**——回车复制成功后展示"已复制到剪贴板"成功反馈（视觉，复用现有绿勾文案），随后 **0.5s 后自动关闭窗口**。反馈不设交互，不拖慢 ⌘V（关窗延时仅 0.5s，且辅助功能用 `⌘TAB` 切换天然快于 0.5s）。<br>BR-11a：键盘 Esc = 关闭剪贴板窗口（等效失焦关窗路径）；仅剪贴板窗口 key window 时消费裸 Esc。 |

### 4.5 线程模型与并发约束

```
 键盘事件(NSEvent, 主线程) ──► local event monitor（可选，开关开启时注册）
                                      │
        ┌───── 消费(return nil) ──────┤
        ▼                             │
  ClipboardHistoryView (MainActor 单线程)
        │  @State: selectedFilter / keyboardSelectionID / searchText
        │  @ObservedObject: HistoryManager(items)
        ▼
  ClipboardHistoryManager.copyToPasteboard (MainActor)
        │ 写 NSPasteboard（同步，无网络/磁盘 IO）
        ▼
  ClipboardHistoryWindowController.close() (MainActor)
```

**并发结论**：本功能全部运行在 MainActor 单线程上；NSPasteboard 写入为同步小操作，无新增后台线程。唯一注意点：`saveToDisk()` 现有 `didSet` 会异步后台写盘（与复制无关，不受影响）。**无并发风险，仅需保证键盘监视器在窗口关闭时被卸载，避免泄漏。**

| 竞态场景 | 危害 | 可回填的 BR |
|----------|------|-------------|
| 窗口关闭但监视器未卸载 | 事件监视器泄漏，消费到其它窗口按键 | BR-17：键盘监视器随窗口 `close()`/`onDisappear` 同步卸载（成对安装/移除）。复制成功后窗口 0.5s 自动关闭（BR-22），`close()` 时即卸载；若监视器在 0.5s 反馈期被卸载，则该路径的 Esc/输入均由窗口系统自然处理。 |
| 快速开关 + 窗口已开 | 监视器重复注册或缺失 | BR-18：开关变更时若窗口已打开，按新状态重新 install/remove，且 `guard` 幂等。 |
| 双击 show 与复制竞态 | 复制后窗口未置 nil，立即再开 | BR-19：沿用现窗口生命周期（close 后 `window=nil`），复制不改变该语义。 |
| （v1.1 增补）快速复制写回 vs `ClipboardMonitor` 0.5s 轮询自环 | 轮询在两次 tick 之间读到自身写回，可能二次入库造成重复/时序错乱 | BR-20：复制写回后，下一次 `checkForChanges` 必须识别 `com.calmbar.fromCalmBar` 标记并跳过（`shouldIgnore` 已含该类型）。建议实现：复制时同步更新 monitor 的 `lastChangeCount`，使写回直接视为"已见"，从根上消除 0.5s 窗口。验证见 V-05。**注意：复制后窗口会停留 0.5s 反馈（BR-22），期间 monitor 可能已触发下一次轮询——`lastChangeCount` 同步必须在写回当下完成，不得依赖关窗时机。** |
| （v1.1 增补）`show()` 复用窗口时 view 不重建 | `.onAppear` 不触发 → 键盘监视器漏装 | BR-21：监视器安装依赖窗口层生命周期而非 view 重建。`show()` 已存在窗口（`makeKeyAndOrderFront`）时若监视器未装则补装；已装则不重装（幂等）。 |
| （v1.2 增补）0.5s 反馈期间再次回车/快速复制 | 反馈窗口内重复触发复制，定时器竞态 | BR-23：复制反馈 0.5s 窗口内，新的回车与 Tab/↑↓/←→ 均被忽略（仅允许 Esc 提前关窗，BR-11a）；0.5s 定时器到后窗口关闭，无二次复制。 |
| （v1.2 增补）关窗/重开与在途 0.5s 定时器 | 定时器未取消，新窗口被旧定时器误关 | BR-24：`close()`/`show()` 时取消在途 0.5s 反馈定时器；定时器回调执行前校验"当前仍为本次复制的那个窗口实例"，否则忽略。 |

### 4.6 核心歧义修正与键盘行为定案（v1.1 增补）

> 本节 v1.1 评审后新增，集中裁定维度四发现的"复制≠粘贴"期望错位与"连发/反馈"取舍，并收敛 F-01~F-10 的结论。

**4.6.1 行为边界：复制 ≠ 粘贴（对应 R-08）**

- 快速复制 = 把选中条目**写入系统剪贴板**，**不自动粘贴**，不尝试把焦点切回原应用。
- 用户需自己切回前台应用并按 `⌘V`。CalmBar 为 `.accessory` 应用（无 Dock 图标，`AppDelegate.swift:19`），窗口关闭后**不会自动回到原应用**——用户用 `⌘TAB` 返回。
- 开关说明与设置页帮助文案**必须写明**："回车后内容已放到系统剪贴板，回原应用按 `⌘V` 粘贴即可。"

**4.6.2 复制成功反馈（v1.2 定案：保留反馈，0.5s 后自动关窗）**

- 快速复制成功后**展示"已复制到剪贴板"成功反馈**（复用现有绿勾文案与 `copiedItemID` 状态），随后 **0.5s 自动关闭窗口**（BR-22）。
- 这是"快速"与"确信"的折中：0.5s 足够肉眼确认复制成功，又几乎不拖慢"回原应用 ⌘V"（辅助功能用户以 `⌘TAB` 切换天然快于 0.5s；即使先按 `⌘V`，剪贴板内容已就位，关窗不吞键）。
- 反馈不设交互、不弹 alert、不可点击，纯视觉，0.5s 后窗口消失。关闭快速复制后此反馈不出现。
- 鼠标路径（UC-04/BR-16）仍为"点击复制 → 停留窗口 + 绿勾"不变，与键盘路径"反馈 0.5s 后关窗"语义不同、互不影响。

**4.6.3 连续复制（连发）体验取舍**

- 保留 R-06"复制后窗口消失"。不做"连发模式/复制后失焦不关窗"。
- 缓解成本：默认开启（BR-01）、Tab 键盘化（BR-04）让"再来一条"的重开路径最短：`开关面板热键` → `Tab×n` → `↑/↓` → `⏎`。
- 0.5s 反馈是刻意的轻微停留，用于确认而非用于打断（BR-22）。该项为已知取舍。

**4.6.4 Esc 关闭窗口**

- 键盘 Esc 关闭剪贴板窗口（BR-11a）。关闭语义与失焦隐藏路径一致，回到上一前台应用。

## 6. 非功能需求

### 6.1 性能（分模式指标）

| 指标 | 快速复制开启 | 关闭 |
|------|--------------|------|
| 打开窗口首帧选中呈现 | 有结果即高亮首位，≤1 帧 | 不渲染任何选中态，零额外开销 |
| 按键响应（Tab/上下/回车） | 本地 `@State` 驱动，目测即时（<16ms 主循环） | 不注册监视器，无路径 |
| 回车→显示反馈→自动关窗端到端 | NSPasteboard 同步写 + 绿勾即时 + 0.5s 延时 `close()`；写入到反馈 <16ms，关窗 ≤0.5s | — |
| 内存/CPU | 仅窗口开启期存在一个 NSEvent 监视器；空闲时无轮询 | 0 |

### 6.2 兼容性（多平台 + 能力边界）

| 项 | 说明 |
|----|------|
| macOS | 原生窗口 + SwiftUI；`onKeyPress`/NSEvent 监视均为 macOS 既有 API。最低部署目标同 App 现状。 |
| 键盘布局 | 方向键与 Return 均为虚拟键码（125/126/36）与字符无关，全布局可用 |
| 中文输入法 | 组词态回车需放行给输入法上屏（`hasMarkedText` 非空时，BR-12b） |
| 既有权限 | 无需新增权限声明；本地事件监视属进程内能力 |

### 6.3 安全与隐私

- 不采集、不上传任何键盘输入；事件监视仅本地进程内判断，命中后即消费，不记录。
- 复制写入沿用 `ClipboardSecurityFilter` 防自环标记，不改变隐私过滤（敏感内容过滤开关不变）。

### 6.4 可靠性

- 监视器泄漏防护：安装/卸载成对（BR-17），`windowWillClose` 钩子兜底卸载。
- 窗口失焦隐藏（`clipboardHideOnBlur`）与快速复制回车关窗不冲突：回车 = 主动隐藏意图（BR-14/BR-22）；失焦路径不动。
- 键盘导航打开期间，鼠标按钮操作始终可用，两路径状态经 BR-09 hover 规则收敛为单一选中源。
- 成功反馈 0.5s 定时器：`close()`/`show()` 时须取消在途定时器（防残留定时器在新窗口误关），见 BR-23/BR-24。
- 反馈期用 `clipboardHideOnBlur` 的失焦逻辑：0.5s 内用户若主动点外部失焦，窗口同样关闭（两种路径收敛），不产生定时器竞态。

### 6.5 技术验证清单（排期前 Spike）

> 以下 6 项建议实现前以最小可运行验证（Spike）确认，避免排期后返工。

| # | Spike 项 | 判定标准 | 风险 |
|---|----------|----------|------|
| V-01 | SwiftUI `TextField` 聚焦态下，local event monitor 能否在 `keyDown` 阶段消费方向键/回车而不干扰输入法组词 | 快速复制开启时：裸方向键移动列表选中、搜索框光标不动；中文组词回车正常上屏；无修饰键方向键不触发 macOS 光标移动 | 中——文本域事件吞并是本功能最大技术不确定性 |
| V-02 | `NSEvent.addLocalMonitorForEvents` 在 SwiftUI `NSHostingController` 窗口内按窗口身份过滤（`===` 比对） | 仅消费剪贴板窗口事件，同 App 其它窗口（设置等）方向键不受影响 | 低——CommandPaletteKit 已验证同模式 |
| V-03 | segmented Picker 通过 `@State selectedFilter` 程序化切换 + 焦点返回搜索框的焦点循环 | 键盘切 Tab 后焦点仍在可输入区，不丢失后续输入 | 低 |
| V-04 | 回车复制富文本/图片/文件后展示反馈并 0.5s 自动关窗，关窗前写盘完成 | `copyToPasteboard` 同步返回后绿勾即时呈现，0.5s 延时关窗，粘贴到目标 App 内容完整 | 低 |
| V-05 | （评审增补）快速复制写回与 `ClipboardMonitor` 0.5s 轮询的自环识别时序 | 快速复制后等待 >1s，历史列表**无重复条目**；`fromCalmBar` 标记在轮询读取时仍存在并被 `shouldIgnore` 跳过 | 中——写回发生在轮询 tick 之外，存在识别窗口 |
| V-06 | （评审增补）Esc 关窗在 `keyDown` 阶段的消费 | 剪贴板窗口 key 时裸 Esc 关窗、不放行；其它窗口 Esc 不受影响 | 低 |

### 6.6 搜索态回车语义的最终裁决（对应 BR-12a）

| 输入焦点位置 | 按回车 | 裁决理由 |
|--------------|--------|----------|
| 搜索框无文字、列表有结果 | = 复制选中项 | 与主流程一致，最快路径 |
| 搜索框有文字（筛选后） | = 复制当前选中项（按 BR-06 规则指向） | "搜索中也生效"设计结论；与 CommandPalette 的 `onSubmit(activateSelection)` 语义对齐；**搜索框不再承担"提交搜索"** |
| 列表为空 | 无副作用（维持现状） | 没有可复制目标 |
| 中文输入法组词中 | 放行给输入法上屏候选 | 保护文本输入基本盘（BR-12b） |

> 语义声明：快速复制开启时，回车在剪贴板窗口内**只有一种含义 = 复制当前选中项**。原"回车提交搜索"职责不再存在（其功能由鼠标/触摸板/点外部取代）。关闭快速复制后回车恢复为文本域 onSubmit 默认行为。

## 8. 易用性设计原则

### 8.1 零配置快速开始

- 「快速复制」**默认开启**：用户首次打开剪贴板即可发现"首位已高亮 + 方向键可用"，无需进设置。

### 8.2 用户可见配置 ≤ 1 项（本功能仅 1 个开关）

| 配置 | 可见性 |
|------|--------|
| `clipboardQuickCopyEnabled` | 设置 → 剪贴板 → 历史窗口与快捷操作（默认开） |

### 8.3 全链路无主动打扰

- 不弹引导、不弹 toast；关闭开关即完全静默回到鼠标模式。
- 设置页开关旁一句人话说明（见 5.3 线框图），不展示"事件监视器/NSEvent"等技术词。

### 8.4 小白语言规范（术语 → 人话）

| 禁止出现（面向用户） | 替换为 |
|---------------------|--------|
| 键盘导航 / 事件监视器 / Tab 循环 / wrap-around | 「可以用 ↑↓ 选择、←→ 切换分类、回车复制」 |
| 富文本 / NSPasteboard / 保留原始格式 | 不需要出现（"复制后内容原样保留"即可，如图片/文件/链接） |
| 选中索引 / selectionID | 「当前高亮的条目」 |
| 复制到系统剪贴板（易被误解为已粘贴） | 说清"复制后窗口自动消失，到你要粘贴的地方按 `⌘V`" |

### 8.5 状态表达简化

- 键盘选中 = 视觉高亮（accent 描边），与"复制成功/已固定"等既有视觉语义可区分即可，不新增第三种状态图标。

### 8.6 一致性检查表（以本 PRD 为准）

| 相关旧表述/行为 | 一致性处理 |
|-----------------|-----------|
| 鼠标点击"复制"后停留并显示成功提示 | **保留**（BR-16），不因键盘复制关窗而改动；键盘路径为"反馈 0.5s 后自动关窗"（BR-22），两者语义不同、互不影响 |
| `clipboardHideOnBlur` 失焦关窗 | 独立路径（BR-14 明确回车主动隐藏不受其约束，二者结果同为关窗；0.5s 反馈期失焦同样关窗，无竞态） |
| 搜索框 `onSubmit` 回车 | v1.1 定案 BR-12a：快速复制开启时回车**永远 = 复制当前选中**，文本域 onSubmit 语义被取代；关闭后恢复。需 V-01 Spike 确认事件顺序 |
| 回车提交搜索的旧表述 | 已废弃：§4.4 表、§6.6、§8.6 均改写为"回车=复制选中"；`searchText` 过滤仅作为"先筛选再复制"的辅助手段 |
| Pin / 删除 / 翻译按钮 hover | 键盘选中仅作用于"可复制条目"，不引入对按钮的键盘焦点劫持（BR-16b） |
| `ClipboardMonitor` 0.5s 轮询自环 | v1.1 定案 BR-20：复制时同步 `lastChangeCount`（在写回当下、不依赖关窗时机），不产生重复历史 |
| 键盘监视器生命周期 | v1.1 定案 BR-17/18/21：随窗口层 install/remove、幂等；不依赖 `.onAppear`（view 可能被复用不重建） |
| v1.0 "复制后立即关窗、无反馈"表述 | v1.2 已弃：改为"成功反馈 + 0.5s 自动关窗"（BR-22）；相关时序图/状态机/线框/性能/Spike 已同步 |
