CalmBar 是一个个人开源的 macOS 工具项目，使用 **Swift 6 + SwiftUI + AppKit** 开发，源码以 **Apache License 2.0** 协议完全公开，从第一行代码到发布维护都由作者独立完成。

## 技术上的取舍

- 全部走系统原生框架：SMC 寄存器读写、IOKit 电源断言、CGEventTap 事件拦截、Vision 文字识别，没有 Electron 或 WebView 容器，没有操作时后台 CPU 占用约 0.1%。
- 需要特权的能力单独拆出 `CalmBarHelper` 特权助手，处理 `/Applications` 下的操作不必反复输入密码。
- 危险操作都留退路：温控在退出与休眠时自动交还 SMC 官方托管；清理统一移入系统废纸篓，误删可以放回。

## 反馈与协作

有问题、有想法或发现 Bug，欢迎到 GitHub 仓库提 Issue。源码、发布记录与 Hy-MT2 部署文档都放在同一个仓库，部署指南位于 `doc/HyMT2部署/` 目录。
